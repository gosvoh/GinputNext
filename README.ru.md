# GInputNext для GTA San Andreas и Logitech Dual Action

Сборка для Windows 10 и классической 32-битной GTA San Andreas. В Updated Classic имеет значение версия `gta_sa.exe`: плагин допускает 1.0 US Compact и 1.0 US Hoodlum. Для других версий проверка исполняемого файла отключает игровой ввод плагина.

## Установка

1. Закройте игру. В GitHub Actions откройте успешный запуск **GInputNext GTASA x86**, скачайте **GInputNext-GTASA.zip**. В Проводнике Windows щёлкните файл правой кнопкой мыши и выберите **Извлечь всё…**. Архив открывается без пароля. Для загрузки артефактов GitHub может потребоваться вход в аккаунт.
2. Убедитесь, что в вашей сборке работает ASI Loader. Переместите прежний GInput (например, `GInputSA.asi`) и прежние копии GInputNext в резервную папку вне игры. Если заменяете GInputNext, сохраните также свой INI. SilentPatch и CLEO можно оставить на месте.
3. Скопируйте четыре файла `GInputNext.asi`, `GInputNext.SDL2.dll`, `GInputNext.ini` и `GInputNext.gamecontrollerdb.txt` рядом с `gta_sa.exe`. Если установлен Mod Loader с поддержкой ASI, можно положить все четыре в отдельную папку `modloader\GInputNext\`. Выберите одно место установки.
4. Подключите Dual Action по USB. Откройте `Win+R → joy.cpl → Свойства` и проверьте оба стика, 12 кнопок и POV. Если крестовина и левый стик поменялись местами, выключите переключение Mode на контроллере. Запустите игру. x360ce, ViGEmBus, Steam Input и инструменты разработки не требуются. Если запуск идёт через Steam, отключите Steam Input для игры, чтобы проверить физический контроллер напрямую.

## Управление

По умолчанию выбран профиль Classic. Левый стик управляет движением и рулением, правый — обзором в поддерживаемых игрой режимах камеры. Оба стика передают промежуточные значения. У Dual Action четыре аналоговые оси. Кнопки 7 и 8 физически цифровые, поэтому действия газа и тормоза при назначении на них имеют два положения.

| Органы управления | Назначение в SDL |
|---|---|
| Кнопки 1, 2, 3, 4 | X, A, B, Y |
| Кнопки 5, 6 | LB, RB |
| Кнопки 7, 8 | LT, RT |
| Кнопки 9, 10 | Back, Start |
| Кнопки 11, 12 | Нажатия левого и правого стика |
| Левый и правый стики | LX/LY и RX/RY |
| Крестовина | Вверх, вправо, вниз, влево и их диагонали |

Start открывает и закрывает паузу. Нажатие F8 открывает настройки GInputNext. В секции `[Sticks]` файла INI можно настроить мёртвые зоны и направление вертикального обзора. Настройку `[Core] ControllerIndex=0` оставьте для первого контроллера.

## Подсказки в сообщениях игры

При активном Logitech Dual Action сообщения с поддерживаемыми тегами действий показывают обозначения кнопок. Например, в Classic при звонке ожидается **L1 (5)**. Цифры соответствуют номерам на корпусе, LS обозначает левый стик, D — крестовину. При переключении на клавиатуру новые сообщения оформляет сама игра. Уже выведенное сообщение может сохранять старую надпись до следующего показа.

Подстановка рассчитана на стандартные режимы пада 0 и 1. Действия без однозначного назначения для выбранного профиля обрабатывает GTA. Буквальный текст вроде «нажмите Tab» в стороннем переводе или CLEO-скрипте не содержит тега действия и сохраняется. Для проверки дождитесь следующего звонка в Classic, предварительно пошевелив стиком. При проблеме проверьте строку `Dual Action message prompts: installed` и пришлите снимок сообщения вместе с логом.

## Диагностика

Журнал `GInputNext.log` создаётся рядом с ASI и перезаписывается при запуске. После сбоя сохраните его копию. Если журнала нет, проверьте путь установки, право записи и журнал ASI Loader или Mod Loader. При сообщении `Unsupported game executable` сверьте версию EXE. Строка `SDL2 runtime accepted` показывает загруженную версию SDL, а `external controller mappings` — путь к базе.

Для Dual Action в журнале ожидаются `vid=046D pid=C216`, `axes=4 buttons=12 hats=1` и установка `Input hook installed`. При строке `Generic joystick connected` выбран резервный путь. Проверьте, что рядом с ASI присутствуют DLL и база из одного архива. При двойных нажатиях проверьте наличие второй копии ASI, старого GInput и виртуального контроллера.

Для проверки ввода выставьте `DebugInput=1` в секции `[Core]`, перезапустите игру и нажимайте кнопки по одной. В журнале `input edge` показывает изменения маски, а `sticks` дважды в секунду показывает нормализованные значения стиков и триггеров. По окончании верните `DebugInput=0`. Для сообщения о проблеме приложите журнал, INI, версию Updated Classic, список модов и описание конкретного действия.

## Ручная проверка на Windows 10

- В главном меню, меню паузы и экране сохранения проверьте навигацию крестовиной, подтверждение, возврат и одиночное срабатывание Start.
- Пешком медленно отклоняйте левый стик, сделайте полный круг и отпустите. Проверьте постепенное изменение скорости, диагонали и отсутствие дрейфа. Правым стиком проверьте обе оси камеры, включая обзор при прицеливании.
- В автомобиле проверьте небольшой и полный поворот руля, газ, тормоз, ручник и обзор. Сверьте все 12 кнопок с таблицей по одной, включая L3/R3 и обе цифровые плечевые кнопки LT/RT.
- Отключите и снова подключите USB во время игры. Переключитесь на клавиатуру и мышь и вернитесь к геймпаду. Отдельно повторите запуск с другим геймпадом.
- Повторите проверки со своими версиями SilentPatch, Mod Loader и CLEO. Проверьте загрузку сохранения, выход из игры и отсутствие двойного ввода. Для оценки производительности сравните время кадра на одном сохранении и маршруте с включённым и выключенным плагином при `DebugInput=0`.

## Удаление

Закройте игру. Удалите четыре установленных файла и созданный `GInputNext.log`, либо отдельную папку мода, если в ней находятся только его файлы. Верните прежний мод и настройки из резервной копии. Сохранения GTA и общий ASI Loader удалять не требуется.
